# تطبيق سَفَرَة (Safarah) - لإدارة ومتابعة حلقات تحفيظ القرآن الكريم

تطبيق Flutter متكامل يعمل بنظام **Offline-First** داخل المسجد مع محرك مزامنة سحابي تلقائي عبر **Supabase** وتقارير **PDF** عربية احترافية لأولياء الأمور.

## محتويات الحزمة
- `supabase_schema.sql`: كود إنشاء الجداول (`users`, `students`, `daily_logs`) في Supabase.
- `pubspec.yaml`: جميع الحزم والمكتبات مضبوطة وجاهزة.
- `lib/`: الكود المصدري الكامل للتطبيق (يشمل فهرس الـ 114 سورة كاملة، المزامنة الخلفية، قاعدة بيانات SQLite، وتقارير الـ PDF).
- `build_app.bat`: سكربت أتمتة لويندوز يقوم بتوليد ملفات الأندرويد وبناء `app-release.apk` وفتح المجلد تلقائياً.
- `.github/workflows/build_apk.yml`: ملف GitHub Actions لبناء الـ APK سحابياً مجاناً.

## خطوات التشغيل السريع
1. فك الضغط عن ملف `safarah_app.zip`.
2. (اختياري للمزامنة السحابية): افتح `supabase_schema.sql` ونفذه في SQL Editor بمشروعك على Supabase، ثم ضع `supabaseUrl` و `supabaseAnonKey` داخل `lib/core/constants.dart`.
3. لبناء ملف الـ APK على ويندوز: اضغط مرتين على ملف `build_app.bat`.


## تحديثات الإصدار المؤسسي
- حالات السجل اليومي أصبحت موحدة: `present`, `absent`, `attended_no_recite`, `excused`.
- تمت إضافة ترقية SQLite من الإصدار 1 إلى 2 مع تحويل أسماء الحالات القديمة دون حذف السجلات.
- لتحديث مشروع Supabase قائم، نفّذ مرة واحدة الملف:
  `supabase_migrations/20261110_attendance_status_expansion.sql`
- للمشروعات الجديدة، استخدم `supabase_schema.sql` المحدّث.
- لوحة الإدارة تعرض مؤشرات تشغيلية فقط، مع شجرة المعلم ← الطلاب، وفترة إحصائية قابلة للتغيير، وتصدير تقرير مؤسسي PDF لكل حلقة.
- الهوية البصرية تستخدم تدرج الزمرد والحدود الذهبية، مع بطاقات وحقول داكنة عالية التباين.
- إعداد CI محفوظ على Java 21 وAndroid SDK 36 وGradle 9.3.1-bin.
